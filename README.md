# Cyclistic Bike-Share Analysis

## Project Overview
This case study explores how casual riders and annual members use Cyclistic's bike-sharing service differently.

## Business Question
How do casual riders and annual members use Cyclistic bikes differently, and how can these differences help encourage casual riders to become annual members?

## Dataset
The analysis uses the April 2020 dataset. Because it covers one month only, the findings may not represent patterns throughout the entire year.

## Objectives
- Understand differences between casual riders and annual members.
- Identify useful patterns in bike-share usage.
- Develop recommendations to help encourage casual riders to consider annual memberships.

## Analysis and Recommendations
The accompanying case study document contains the business problem, analysis, findings, and recommendations.
